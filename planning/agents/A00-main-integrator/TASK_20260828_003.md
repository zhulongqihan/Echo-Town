# D2 MVP垂直切片任务

## 唯一主问题

制作《回声镇：一生一局》的可运行网页 MVP，验证一段人生能否在手机/电脑上完成，并让下一世看到上一世的关系、遗物与小镇变化。

## 必须交付

- `development/game/` 中可由静态服务器直接打开的游戏入口、样式、规则与内容数据；
- 首屏、人生事件、选择反馈、结算、继承、重开、继续和本地存档；
- 可验证的跨局变化：至少一种遗物继承、一个关系变化、一个小镇状态变化；
- PWA manifest 与离线缓存基础能力；
- 真实浏览器流程验收记录与截图证据。

## 约束

- 全中文、无外部运行时服务、无运行时AI；
- 代码只写入`development/`及本任务明确列出的状态/交接文件；
- 未锁定的正式版规则使用实现假设，不回写成G1-G10锁定事实；
- 所有关键操作可用键盘和触屏完成，并支持`prefers-reduced-motion`。

## 验收标准

- 新玩家可在一次浏览器会话中完成一生并看到结算；
- 至少三个关键选择会改变属性、关系或小镇状态，并产生文字反馈；
- 点击“下一世”后能在五秒内进入新人生，且至少看见上一世留下的一项变化；
- 刷新页面后“继续人生”可恢复当前阶段；
- 完成两世后刷新页面，跨世记忆仍存在；
- 结构校验退出码为0，Playwright真实浏览器冒烟流程通过。

## 完成结论

- 已完成：`development/game/`可运行网页MVP、PWA离线入口、D2浏览器验收记录和截图证据。
- 结果：所有D2验收标准通过；任务关闭，租约释放。
