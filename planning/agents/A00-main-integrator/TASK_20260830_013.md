# A00 D5视觉声音与人生片段整合任务

## 任务目的

在D4生活经营循环上补齐阶段氛围、行动记忆和声音反馈，让玩家更容易读懂“我现在在哪、刚才做了什么、这一笔结果有多重”，同时保持离线和可访问性。

## 交付验收

- 五阶段都有项目内场景图，加载失败有文字回退；
- 用户点击声音开关后能听到阶段配乐与关键行动音效，静音/不支持AudioContext时主循环不受影响；
- 至少12个人生片段可被真实行动解锁，并在当前世、结算和镇志至少两处回看；
- save v7能保存媒体设置和片段，刷新、导入导出和D4字段归一化不回归；
- 长流程、移动端、减弱动效、无媒体回退和项目治理校验全部通过。
