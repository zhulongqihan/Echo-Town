# D5视觉声音与人生片段反馈层

## 触发原因

用户试玩D4后仍认为内容不够丰富，并明确要求加入图片和配乐。D4已经补上了生活经营的动作和数值，但阶段之间的视觉身份、行动留下的记忆点和情绪反馈仍偏弱。

## 目标

1. 为五个成长阶段提供统一画风的项目内场景图，让玩家一眼知道自己处在哪段人生；
2. 用可见的12个人生片段收集，把第一次学习、第一笔工资、第一次欠账、一次远行等行动结果变成可回看的记忆；
3. 用离线本地合成配乐和短音效区分成长、赚钱、购买、账单、结算等状态；
4. 提供清晰的声音开关、静音文本反馈和浏览器不支持时的安全回退；
5. 媒体层只增强识别和反馈，不改变D4的行动点、经济和跨世规则边界。

## 临时契约

- 阶段图为静态本地图片，按童年、少年、初入社会、成家立业、后半生绑定；
- 配乐使用Web Audio本地合成，不请求外部音频、不自动强制播放；首次由用户点击声音按钮后启动，可随时静音；
- 人生片段为固定 authored 内容，最多12条，按生活行动、工作、消费、账单、事件和结算条件解锁；
- save v7新增声音设置、人生片段和媒体状态，旧D4存档仍保留但不混合两套规则；
- 图片、音效和片段均必须有文字等价反馈，降低动效、静音和低性能设备仍可完整游玩。

## 角色接口

| 角色 | 本轮专项问题 |
| --- | --- |
| A02 | 片段触发是否与状态一致，是否重复解锁或阻断主循环 |
| A03 | 五阶段画面、生活记忆和声音情绪是否形成独立世体验 |
| A04 | 图片/声音触发文案、片段字段和固定内容审校 |
| A05 | 声音开关、静音降级、对比度、焦点、移动布局和减少动效 |
| A06 | 静态资源缓存、save v7归一化、浏览器AudioContext兼容与离线 |
| A07 | 首屏可理解性、媒体失败回退、完整流程、移动端与P0/P1/P2风险 |
| A00 | 唯一写入、冲突整合、内部验收、回退和GitHub交付 |

## 停止与回退

若图片或声音让玩家忽略行动与结果，优先降低媒体占比并保留文字；若浏览器不支持Web Audio，必须仍可完成一生；若媒体资源导致离线缓存或存档异常，回退到D4代码和媒体开关关闭状态。
