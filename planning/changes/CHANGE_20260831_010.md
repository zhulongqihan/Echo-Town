# D5核心循环整体重构与配乐解锁再验证

## 触发原因

用户试玩D5后仍然提不起游玩兴趣。已有生活行动、工作、阶段图片和片段虽然增加了内容，但玩家仍可能把节点当作一串等权按钮；同时用户反馈主动打开配乐后听不到声音。

## 目标

1. 把每个节点的生活安排从“尽量花完点数”改成“2点行动的明确押注”，让工作、成长、休息和关系形成真实取舍；
2. 首屏只突出与本世愿望和当前状态最相关的生活行动，其它操作仍可展开，不隐藏系统能力；
3. 在节点顶部给出阶段正在追问的问题，并把上一事件的 future 作为下一节点的“回声”，让后果跨节点可见；
4. 修复本地Web Audio的用户手势解锁：点击后等待AudioContext恢复，播放可听见确认音和阶段音，失败时明确提示并保留文字回退；
5. 保持旧存档可归一化、离线/PWA、确定性规则和全流程可完成，不把再验证参数写成最终GDD。

## 临时契约

- `actionPointsPerRound` 暂改为2；工作仍按2点计费，旧save v7读入时自动收敛到当前上限；
- 生活行动按目标、年龄和资源状态动态分为推荐列表与“其它生活安排”，推荐不改变规则，只改变首屏信息层级；
- `stageFocus` 为固定 authored 文案；`carryForward` 保存最近一次人生事件的标题、后果与年龄，用于下一节点展示；
- Web Audio首次由用户点击启动，`AudioContext`恢复后立即播放确认音；浏览器拒绝时回退为清晰的文字提示，不请求外部音频。

## 角色接口

| 角色 | 本轮专项问题 |
| --- | --- |
| A02 | 2点行动与工作/账单/休息的可达性、是否出现死局 |
| A03 | 阶段问题与回声文案是否让一世有连续的情绪线 |
| A04 | 推荐行动映射是否与目标和年龄一致，未推荐能力是否仍可访问 |
| A05 | 首屏层级、音频开关、移动端触控与降级反馈 |
| A06 | save v7归一化、PWA缓存版本和离线资源一致性 |
| A07 | 真实浏览器音频状态、23节点长流程、移动端溢出和控制台错误 |
| A00 | 唯一写入、整合、验证、回退与交付 |

## 停止与回退

如果2点行动导致目标不可达、生活费无法支付或用户无法理解推荐与其它的区别，回退到3点规则并保留阶段问题与回声提示；如果浏览器拒绝音频，必须允许静音完成一生；若缓存或旧存档出现破坏性问题，回退到D5 v14资源并关闭音频自动恢复。

## 本轮实现与复核结果（2026-09-03）

- 研究并对照《中国式家长》《人生重开模拟器》后，完成 P1/P2：10 选 3 天赋、20 点四属性构筑、18 张机会牌、12 项兴趣、8 位命名角色、兴趣加权抽牌、关系镜像、路线结局与结算摘要。
- 机会牌现已成为每个成长节点的独立决策层；选择会同时写入资源、技能、兴趣、角色、关系、路线、目标和日志，跳过也有明确反馈。
- 真实浏览器复核：首屏四步构筑可用；机会牌会锁住生活安排直到处理；选择机会后兴趣/角色变化可见；生活行动能继续积累兴趣；音频点击后 `supported=true, enabled=true, state=running`；控制台 0 错误。
- 自动校验通过：内容校验、save v7 契约、项目治理校验均通过；P3 仍保留为后续增强项（天赋记忆、因果回放、更多结局与隐藏路线）。
