# D4生活经营沙盒与高可玩度循环

## 触发原因

用户认为D3丰富版仍然更像“节点很多的线性选择”，没有达到《中国式家长》《众生游》和打工赚钱模拟器那种能持续规划、经营和复盘的可玩度。缺口不是事件数量，而是每个节点内没有中层循环：玩家没有足够的行动安排、工作选择、收入支出、物品使用和生活取舍。

## 目标

1. 每个成长节点从“一次选择”升级为“生活安排3点 + 人生事件1次”；
2. 增加学习、休息、关系、照料、购物、探索和工作班等可重复行动；
3. 建立工资、生活支出、压力/健康风险、工作经验和物品库存的可解释经营链；
4. 让不同身份、天赋、愿望和遗产真正改变可用行动，而不是只改开场文字；
5. 把行动收益、物品加成、职业痕迹和现金流带入结算、成就、彩蛋与下一世；
6. 用长流程、随机策略、移动端、存档和用户试玩验证“更像游戏而不是更多文本”。

## 临时玩法契约

- D3的5阶段、23节点、69个人生事件保留；每节点新增3点生活行动；
- 生活行动包含学习/练习、休息恢复、关系维护、家庭照料、城镇活动、购物、职业工作班；
- 每个节点自动结算生活支出，现金不足会转成债务/压力，但存在多条赚钱和降压路径；
- 工作班区分收入、精力、身体、压力、技能和小镇影响，部分工作有前置能力要求；
- 物品有价格、库存上限和明确使用场景，遗产可以直接交接物品或物品效果；
- save v6，固定seed，不使用`Math.random`，运行时不联网、不调用AI；
- “超过参考作品”是产品追求，不是本轮未经用户验证的事实。

## 停止与回退

若生活层让玩家不知道先做什么，优先收敛成“本节点3点行动 + 一次事件”的清楚节奏；若经济系统出现全锁或只剩一种最优工作，先修正收益/代价和兜底路径，不继续增加职业数量。旧版D3代码可由Git提交回退，D4参数不写入最终GDD。
