# D5视觉声音与人生片段反馈层提案

本提案承接`CHANGE-20260830-009`，只用于开发验证，不替代04/05/06/08/09/11的正式门禁结论。

## 设计判断

D4的问题已经从“没有经营动作”推进到“动作有了，但人生记忆和阶段身份仍不够厚”。新增内容分成三个层级：

```text
阶段场景图 = 识别我现在在哪里
人生片段 = 记住我刚刚做成了什么
配乐/音效 = 感受到这次结果的重量
```

三层必须绑定现有状态：阶段图跟年龄走，片段跟实际行动/账单/工作/购买/事件走，声音跟行动结果和压力走。它们不单独制造新的隐藏规则。

## D5切片

- 五张横向阶段场景图：童年院子、少年学校、初入社会的车站/街区、成家后的厨房与小镇、后半生的桥与灯；统一低饱和绘本质感，无图中文字和品牌标识；
- 一个阶段配乐控制器：点击开启后按阶段切换和弦/音型，压力高时加入低频脉冲，赚钱/购买/账单/结算播放短反馈音；
- 十二个人生片段：第一次学习、第一次修理、第一笔工资、第一次购买、第一笔生活费、第一次欠账、换工作、夜班远行、照料家人、镇上项目、写进镇志、给下一世留门；
- 人生片段显示在当前世经营区、结算页和镇志中，解锁时提供文字/音效双重反馈，静音仍显示文字。

## 可玩性护栏

- 不用图片替代代价、条件或结果文字；
- 不用声音遮蔽重要信息，不默认自动播放；
- 片段是回看和收集奖励，不增加必须学习的隐藏规则；
- 每一世仍能独立完成，跨世只通过既有遗产/小镇和D5的收集记录形成回声；
- 媒体资源失败时，主循环、存档、结算和导入导出仍可用。
