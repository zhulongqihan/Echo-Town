# 《回声镇：一生一局》玩法与存档说明

双击项目或离线包根目录的 `index.html` 开始游戏。请保留解压后的目录结构，图片和脚本会从本地读取。

## 开局

可以选择“手艺谋生”“学业职业”“关系共建”的推荐配置，再调整身份、天赋、属性和愿望；也可以完全自定义。开局有 20 点属性额度，并选择 3 个天赋。

| 属性 | 实际作用 |
| --- | --- |
| 外在 | 每 4 点为表达、体谅及开作坊相关检定增加 1 点基础得分 |
| 智识 | 每 4 点为学识检定增加 1 点基础得分 |
| 体魄 | 每 4 点增加 1 点初始精力上限，基础上限为 10 |
| 家境 | 每点增加 2 元初始现金 |

身份、天赋和继承的遗产也会影响初始状态。天赋带来的属性先兑现，再计算对应收益；精力上限还会加上遗产明确提供的上限增益。开局预览会展示实际结果。三条路线仅决定当前追踪的目标，不限制你学习其它技能或选择其它方向。

## 每个节点怎么过

1. **处理机会。** 从本节点机会牌中选择一张，或直接跳过。
2. **安排生活。** 每节点有 2 点行动。学习、动手、见面、照料、休息、探索和记录通常各占 1 点；六种工作均占 2 点，买一件物品占 1 点。可随时结束剩余安排。
3. **选择人生事件。** 根据现金、精力、技能和经历选择一项行动。每节点都有无前置、零成本的保守选项。
4. **阅读结果并继续。** 反馈会说明实际变化和检定结果，确认后进入下一节点。

主界面会显示当前目标、行动点、现金、精力和下一笔生活费。先看事件需要什么，再决定生活安排，有助于给重要选择留下余地。

进入新节点时自然恢复 3 点精力，不超过上限。每节点第一次休息基础恢复 2 点，第二次恢复 1 点；机会与物品可能改变具体效果，以行动预览为准。刷新、重新打开页面或导入存档不会额外恢复精力。

现金或精力不足时，相关主动行动不可执行。生活费现金不足的部分会转为欠款；借款也会增加债务，不算劳动收入。可以用现有现金还款，还款不占行动点，当前规则不收利息。

## 三条路线与阶段成果

目标在童年 11 岁、少年 17 岁、青年 28 岁、中年 49 岁、晚年 75 岁结算。界面会逐项显示已经做到与尚缺的条件。未完成时正常进入下一阶段，之后的成长不会补发以前的成果。

| 路线 | 从早年到晚年的主要方向 |
| --- | --- |
| 手艺谋生 | 实际修理 → 修理铺工作 → 靠工作维持生活 → 开作坊并继续经营 → 交接手艺 |
| 学业职业 | 学习方法 → 升学或辅导 → 有偿运用知识 → 专业调查或稳定传授 → 留下教材与记录 |
| 关系共建 | 求助互助 → 共同承担 → 持续维护关系 → 家庭分担或公共协作 → 重聚与共同照料 |

每条路线还有一段跨越多个年龄的事件链，后面的选择会回应前面的经历。检定失败不会被记录成成功成果；即使失败，部分事件链仍允许带着真实记录继续尝试。

各阶段的通常技能增长上限依次为 4、6、8、10、10。天赋、遗产和已有旧进度中的更高数值会保留；普通成长不会把已有技能降低。

开局选择的六种愿望依据实际工作、照料、共同经历、公共事务、记录或自主选择判断。重复单一行动可以积累技能，但不能代替整条人生路线需要的经历。

## 结局与下一世

75 岁的最后一个事件仍可以作出路线交接。满足条件时，可以留维修册、整理教材或交出共同照料的联系表；这些只影响晚年成果，不补发前四阶段记录。

结算分别展示这一世的成果、付出的代价和能够留下的遗产。最多选择 3 件已获得遗产带入下一世：

- **趁手工具：** 增加下一世手艺，携带工具，并在 8 岁开启沿刻痕练习拆装的选择。
- **写满批注的笔记：** 增加下一世学识，携带笔记本，并在 13 岁开启整理旧批注的选择，可以接入 21 岁试讲。
- **没有寄出的信：** 增加下一世朋友关系，携带旧手机，并在 32 岁开启共同照料的选择。

镇志保留历世回顾、工作与现金流记录，小镇基础和收藏也会延续。

## 保存与迁移

当前使用 v8 存档。正常游玩会尝试自动保存；请留意界面上的保存状态。本地存储不可用时，当前页面仍可游玩，可使用导出备份保存进度。

导出文件为紧凑 JSON。导入接受不超过 2 MiB 的原文件，经过解析后的有效紧凑存档须不超过 512 KiB。导入会先校验并备份当前有效进度，成功写入后才切换游戏；解析、备份或保存失败时，当前进度保持不变。

v7 进度会迁移到独立的 v8 存储位置，原始 v7 保留。节点、资源、剩余行动、机会牌、已选事件、反馈、遗产选择、世数、镇志与收藏继续使用，已经产生的结局和其中的旧制愿望结果不重算。

旧经历没有足够证据时，过去的阶段标为“旧制经历”，不会判成失败，也不会冒充新成果。当前阶段只在能够证明剩余正常操作足以完成目标时接入；其它目标从下一个完整阶段开始。已经到最后事件反馈或结局的旧档，从下一世完整启用新目标。

发现损坏或无法安全恢复的本地存档时，游戏会保护原档，暂停会覆盖它的推进操作。可以导入有效备份，或在设置中明确清除后重新开始。清除当前进度后，保留的 v7 不会自动恢复回来。

## 声音、键盘与离线

配乐默认关闭，可以主动开启、调节音量或试听。试听不会替你打开持续配乐。系统减少动画设置、大字模式和键盘操作均可使用；事件阶段的数字键与屏幕可见选项对应，输入文字时不会触发选择。

游戏的 10 张场景图片使用本地 WebP，共约 1.53 MiB。音频由浏览器本地合成。图片或音频加载失败不会阻止文字玩法。

双击文件即可离线游玩。要使用 PWA，请通过静态服务器打开，并在支持的浏览器中安装。首次缓存完成后可离线使用。遇到“保存并更新”时，点击后会先保存，再刷新到新版本；保存失败时不会自动刷新。
