# 《回声镇：一生一局》

在回声镇，从 6 岁走到 75 岁。你可以靠手艺谋生，用学识打开职业道路，也可以让家人与邻里共同承担生活。每一世都有新的选择，小镇会留下你做过的事。

这是全中文、单机、离线可玩的网页游戏，无需账号、安装或联网服务。

## 开始游戏

双击项目根目录的 [`index.html`](index.html) 即可开始。使用离线包时，先完整解压，再打开包内根目录的 `index.html`。

- [下载 D6／v8 离线包](output/releases/echo-town-strategy-v8-20261015.zip)
- [玩法与存档说明](development/game/README.md)

希望安装为 PWA 时，用静态服务器提供项目目录，再通过浏览器打开。首次打开并缓存完成后，可继续离线游玩；双击入口本身不需要服务器。

## 怎样经营这一生

一世有 5 个阶段、23 个节点。每个节点依次处理**机会、生活安排、人生事件和结果**。

先看当前阶段目标与本节点事件，再安排手中的 2 点行动。日常行动一般占 1 点，工作占 2 点；精力、现金和门槛都要付得起。下一节点会自然恢复精力，但也可能迎来新的生活费。行动前可以查看代价、执行后余额与检定风险。

三条路线提供可编辑的推荐开局，也允许完整自定义：

| 路线 | 你会面对的经营问题 |
| --- | --- |
| 手艺谋生 | 从修好东西到有偿工作，准备开张资金，经营作坊并培养接班人 |
| 学业职业 | 在学习、辅导与职业机会之间分配时间，留下可以传授的专业成果 |
| 关系共建 | 从求助和互助开始，在家庭分担、公共协作与关系维护之间安排精力 |

路线只改变当前追踪重点，随时可以兼修或转向。阶段目标在 11、17、28、49、75 岁分别结算；没有完成也能继续，之后的阶段不要求补齐之前的目标。

困难时可以跳过机会、结束剩余生活安排，或选择不消耗资源的保守事件。借款会形成债务，还款不占行动点。结局会同时记录成果与代价，单纯把技能刷高不能替代实际经历。

75 岁时留下这一世的成果，再从已获得的遗产中最多选择 3 件带入下一世。工具、笔记与书信除了改变开局状态，还会开启具体的新事件选择。

## 存档、声音与显示

- 进度保存在当前浏览器中。换设备、换浏览器或移动文件前，可先在设置中导出 JSON 备份，再到新位置导入。
- v7 进度可以迁移到 v8，原始 v7 存档保留。无法可靠接入新目标的旧阶段显示为“旧制经历”，已有事件结果和结局保持原样。
- 配乐默认关闭，可主动开启、调节音量和试听。静音或音频不可用时仍可正常游玩。
- 支持键盘操作、大字模式、系统减少动画设置，以及电脑和手机布局。

当前内容版本为 **6.0.0**，存档版本为 **v8**。游戏使用本地图片和合成音频，不依赖在线素材服务。

代码与接口说明见[当前运行时契约](docs/current_runtime_contract.md)。根目录 `index.html` 是稳定入口，游戏源码位于 `development/game/`。
