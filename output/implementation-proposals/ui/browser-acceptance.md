# v8 界面真实浏览器验收

本表是待执行步骤，不是已通过报告。使用独立浏览器测试资料目录与本机测试服务器；不要覆盖玩家存档。每项记录页面地址、视口、实际结果及截图。以集成后的 `development/game/` 为准。

## 1. 手机首屏与操作长度

1. 视口设为 **390 × 844、缩放 100%**。走进小镇，分别选择三条推荐路线，确认四项自定义仍能展开，天赋可替换，属性总点数可调整回 20，六个愿望均能选择。
2. 开始一世，回到滚动顶部，截取机会阶段首屏。当前阶段目标、现金、精力、行动点、下一笔生活费，以及至少一个可点击的主要选择应在首屏可见；页面不得横向滚动。
3. 选择或跳过机会，截图生活阶段；使用一个行动，再结束安排，截图事件阶段；执行事件，截图结果阶段。一次只显示当前操作阶段，已完成步骤能展开摘要。先完成一次成本不足场景，确认禁用原因具体，仍可休息、放弃行动或使用保守事件继续。
4. 在 6、18、36、75 岁重复检查。默认折叠状态下，从本节点顶部到当前阶段最后一个主要操作按钮应约在 **1688 px** 内；历史、场景、状态等主动展开内容另记。成年时工作按钮直接出现，不需要打开“集市、库存与生活记录”。
5. 开启大字模式和系统减少动画，确认文字不遮挡按钮、没有横向滚动。另以 1440 × 1000 检查桌面布局与关闭的状态面板。

可只读记录几何信息：`document.documentElement.scrollWidth <= innerWidth`，以及目标、资源条、首个可用选择的 `getBoundingClientRect()`；截图仍需人工阅读检查。

## 2. 键盘与中断恢复

- 仅用 Tab、Shift+Tab、Enter、空格完成预设、天赋替换、属性调整、机会跳过、生活安排、事件和继续长大。焦点须清楚，构筑选择刷新后不能丢到页面起点。
- 事件阶段按 1—9 选择对应事件；机会、生活阶段或输入框、音量滑块、路线下拉框内按数字不得触发事件。
- 每次行动后能读到反馈，焦点落在反馈或下一步；在机会已选、剩余 1 点、剩余 0 点、事件结果、遗产选择五个断点刷新，确认资源、选择和阶段不重复结算。
- 完成一世，确认成果、身体／压力／债务代价、遗产用途可读；最多选三件。开始下一世，找到一项由继承物开启的实际新选择。

## 3. 导入失败与保存失败

1. 导出一份有效备份并记录当前内存快照与 v8 主存储键原文。导入损坏 JSON、空壳对象及超过 2 MiB 文件：显示失败，内存和主档均保持原样；同一文件可再次选择触发导入。
2. 在隔离页面中，临时令 `Storage.prototype.setItem` 抛出 `QuotaExceededError`，再导入有效备份。应提示备份／保存失败，不显示“已导入”，内存和主档不切换。结束后立即恢复原方法。
3. 同样模拟存储失败后执行普通行动：当前页可继续，明确提示保存失败并建议导出；不得显示保存成功。清档失败也必须保留当前人生。
4. 成功导入 v7 的机会、生活、事件反馈、遗产断点各一份：旧档原文保留，新目标显示“旧制经历”或约定接入阶段。导出当前 v8 后重新导入，记录字节数及往返一致性。

## 4. 声音与静音

- 新页面保持静音；打开“声音与显示”，在配乐关闭时试听，试听结束后配乐开关仍关闭。音量调至 0 再试听应无声。
- 打开配乐，调整音量后刷新，首次手势恢复时音量应保持。关闭配乐后当前正在发声的音符应立即收束；阶段与行动文字反馈正常。
- **先开启配乐，再导入 `sound:false` 的有效存档，及清除当前世代**：界面和实际播放状态都应关闭，不能出现按钮显示“打开配乐”而仍在发声。
- 切换后台再返回、切换阶段，不能叠加多个循环。无 Web Audio 支持时，主流程可完整游玩。

## 5. 更新提示、离线与图片失败

- 在已有旧 service worker 控制的隔离站点，部署带新缓存版本的同一游戏并触发检查。等待安装完成后出现“保存并更新”，默认不强制刷新。
- 点击更新：先保存，后激活等待中的 worker，再刷新；刷新后节点、资源、行动点与反馈保留。令保存失败再点更新：提示失败，禁止激活或刷新。
- `window.dispatchEvent(new CustomEvent('echo-town-update-ready'))` 可单独验证提示按钮，但不能用它替代真实 worker 更新验收。
- 首次在线加载后断网刷新并完成一个节点。阻断一张 WebP 后再次渲染，显示图片不可用提示且文字选择正常；根目录双击入口也能进入游戏，`file://` 下无 worker 注册报错。

完成后由实际执行者填写“通过／失败／未测”，不得把静态检查或事件模拟记作浏览器完整验收通过。
