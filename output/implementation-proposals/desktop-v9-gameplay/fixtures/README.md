# 青年手艺体验存档

在游戏首页选择“导入存档”，打开对应的JSON文件即可继续这一段人生。导入会切换当前进度；想保留自己的存档，可先使用“导出存档”。

| 存档 | 从哪里开始 | 可以体验什么 |
|---|---|---|
| youth-19-offer.json | 19岁，现金27，精力9 | 面对“建立固定客源”的邀请，决定继续稳定帮工，还是为以后独立接活留出准备时间 |
| youth-28-feedback.json | 28岁，现金41，精力7 | 查看此前选择的结果，再进入中年 |
| middle-32-independent-work.json | 32岁，现金36，精力10 | 比较普通帮工、小镇项目与固定客户维修，权衡收入、精力、压力和成长 |

三个存档是同一开局在不同人生节点的进度，都可以继续玩到75岁。每个节点仍有原来的2点生活行动，机会、账单和人生事件照常发生。

固定客户维修占2点生活行动，每次收入14、消耗4精力、压力增加2；小镇项目同样占2点行动，收入11、消耗2精力，并增加公共建设。安排工作时也要给本节点的人生事件留出精力，可以穿插普通工作或休息。购买工具能帮助手艺成长，但不保证比其他工作赚到更多现金。

第一次体验建议从19岁开始，让选择自然延续。想先看看长期投入改变了什么，可以直接打开32岁的存档。
