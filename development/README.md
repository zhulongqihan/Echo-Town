# 《回声镇：一生一局》开发框架入口

这里是《回声镇：一生一局》的工程入口。当前`game/`是已完成内部审计的免费离线旧版可玩回退构建；用户试玩已确认核心循环需要重规划，新的玩法垂直切片尚未替换旧版入口。

正式版继续扩展前必须满足：

- `planning/contracts/framework-entry-contract.md`的开发解锁条件全部满足；
- G10最终GDD已审计并获得用户明确批准；当前文档已生成，等待用户试玩回填与批准；
- `planning/tools/validate_project.py`通过；
- A00签发具体开发任务和唯一写入租约。

当前目录职责：

- `architecture/`：解锁后的实现架构和接口；
- `game/`：当前可玩构建本体实现；
- `content/`：D2固定内容说明与后续内容工程入口；
- `tests/`：规则、内容、存档、浏览器、移动端和无障碍测试；
- `release/`：构建、版本、迁移、回滚和发布材料。

## 试玩入口约定

- 项目工作区的唯一用户试玩入口是根目录`index.html`；打开后自动进入当前可玩构建。
- `development/game/`是唯一游戏源码目录，`development/game/index.html`只作为源码入口，不与根目录复制两份游戏。
- 所有后续可试玩构建和发行准备都必须保留根目录`index.html`这一稳定入口；若源码位置变化，只更新根入口指向，不改变用户入口约定。

G10用户批准前，`development/`中的实现可作为可玩构建交付和验证证据，但不得自动扩大正式版范围。
