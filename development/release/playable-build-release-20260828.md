# 《回声镇：一生一局》可玩构建发行说明

## 当前构建

- 入口：`development/game/index.html`
- 分发包：`output/releases/echo-town-playable-20260828.zip`
- SHA-256：`5531FE1783251051C5A3989871E571C77A2D059E4A274FD6BCD160FE4801AB7B`
- 内容：12个生命节点、每节点3个选择、4条条件结局、人物关系、发现、遗物和历世镇志。
- 今生方向：每一世可选择修路、记事或守灯方向，改变起始能力并写入历世档案。
- 存档：localStorage v3，兼容v1/v2；游戏首页提供JSON导出与导入。
- 边界：免费、完全离线、不收集数据、无账号、无多人、无内购、运行时不依赖AI。
- PWA：缓存版本`echo-town-mvp-v13`，含192和512安装图标。

## 换设备

在旧设备首页点击“导出存档”，把`echo-town-save.json`传到新设备，在新设备首页点击“导入存档”。这是用户主动操作的本地备份，不会上传任何服务。

## 开始试玩

下载并解压发行包，双击其中的`index.html`即可开始；核心游戏不需要联网。若希望使用PWA安装/应用壳能力，可用本地静态服务器打开同一目录。
