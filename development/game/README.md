# 游戏本体入口

《回声镇：一生一局》的丰富版人生循环切片。最简单的试玩方式是解压后双击根目录 `index.html`；游戏本体不需要联网、账号、安装或运行时 AI。若希望启用 PWA 离线缓存，用任意本地静态服务器打开即可。

## 当前可玩范围

- 一世从 6 岁走到 75 岁，固定经历 23 个成长节点，分为童年、少年、初入社会、成家立业、后半生五个阶段；每个节点从 3 个行动中选 1 个，共 69 个互斥选择；
- 开局选择 5 种人生起点、8 种天赋和 6 个本世愿望；起点决定初始状态，天赋改变路线，愿望让玩家有清晰的可追求方向；
- 经营钱、精力、身体、心气、压力五种资源；学习学识、手艺、表达、体谅、胆识五项技能；维护家人、师长、朋友、伴侣、晚辈、邻里六段关系；
- 每个行动在执行前显示代价、开放条件、预期变化和目标贡献；部分行动触发确定性检定，成功/失败都留下可读结果；
- 修理铺、河桥、学校、集市、镇志五项小镇基础跨世累积；一世结算从已解锁遗产中最多选择 3 件，下一世会把它们转成真实的初始资源、能力、关系或小镇入口；
- 12 项成就、8 条彩蛋和镇志档案提供长期收集、复盘和再开一局的理由；成就与彩蛋都在游戏内显示发现条件和结果，不依赖隐藏联网服务；
- localStorage v5 存档，旧版存档键保留但不自动迁移；支持导出 JSON、导入 JSON、清除当前世代和镇志回看；
- 全中文、本地单机、确定性 seed、响应式布局、键盘 1 / 2 / 3 选择、大字模式和基础 PWA 离线缓存。

## 设计边界

这是用于验证“目标明确、养成可规划、选择有代价、结算有成就、下一世有用途”的丰富版可玩切片，不是最终 GDD 锁定。内容采用固定 authored 数据；运行时不依赖联网、多人、内购或 AI。每世可以独立完成，同时通过小镇基础和最多三件遗产形成长期回声。

## 内容与代码

- `content.js`：静态起点、天赋、愿望、阶段、23 个成长节点、69 个行动、遗产、成就和彩蛋；
- `game.js`：存档、状态转移、条件与检定、结算、成就解锁、遗产交接和渲染逻辑；
- `../content/content-manifest.json`：内容数量与 ID 契约；
- `../content/content-review.json`：A04 内容责任、A00 整合审阅和内容质量边界；
- `../tests/rich-loop-acceptance-20260829.md`：丰富版长流程、跨世、成就、彩蛋和移动端验收表。
