# 游戏本体入口

《回声镇：一生一局》的本地网页游戏入口。最简单的试玩方式是解压发行包后双击`index.html`；游戏核心不需要联网、账号、安装或运行时AI。若希望浏览器启用PWA安装和离线应用壳，再用任意本地静态服务器打开它即可。

## 当前可玩范围

- 12个生命节点：7、12、16、28、36、45、52、60、67、74、82、96岁；
- 每个节点三个选择，选择后显示代价、属性变化和留下的回声；
- 结算、下一世、遗物、人物关系、发现和小镇状态继承；
- 多个可解释结局，历世档案页记录每一世的结局、回声、选择与发现；
- 每一世开局可选择“修路的人 / 记事的人 / 守灯的人”三种方向，方向会改变起始能力并记录进历世档案；
- localStorage v3存档，兼容v1/v2，支持导出JSON、导入JSON和清除本地存档；导出文件可作为换设备备份；每一世保存确定性seed，便于复现规则结果；
- 存档边界保护：拒绝过大/损坏文件，归一化越界字段，档案页转义导入文本，本地存储不可用时给出反馈；
- PWA基础资源（含192/512安装图标）、离线缓存、桌面/手机响应式布局、键盘1/2/3选择和减少动画。

## 开发边界

这里的实现是已确认产品边界下的本地可玩构建，已通过G2-G9内部门禁和G10总审计；仍需用户本人试玩回填实际时长、跨世理解、重玩意愿和设备体验后，才能关闭最终批准状态。保持全中文、单机、无账号、无联网业务、无多人、无内购、不收集数据，运行时不依赖AI。
