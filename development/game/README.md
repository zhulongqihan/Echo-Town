# 游戏本体入口

《回声镇：一生一局》的 D5 生活经营沙盒切片。最简单的试玩方式是解压后双击根目录 `index.html`；游戏本体不需要联网、账号、安装或运行时 AI。若希望启用 PWA 离线缓存，用任意本地静态服务器打开即可。

## 当前可玩范围

- 一世从 6 岁走到 75 岁，固定经历 23 个成长节点，分为童年、少年、初入社会、成家立业、后半生五个阶段；每个节点先分配 3 点生活行动，再从 3 个事件行动中选 1 个；
- 生活层提供学习、动手、社交、照料、休息、探索、记录 7 种日常安排，以及修理铺、辅导、集市、送货、夜班、小镇项目 6 种工作；
- 工资、年龄生活费、现金不足形成的债务压力、工作履历、库存和物品加成会进入结算；6 件物品有价格、库存上限和明确使用场景；
- 开局选择 5 种人生起点、8 种天赋和 6 个本世愿望；起点决定初始状态，天赋改变路线，愿望让玩家有清晰的可追求方向；
- 经营钱、精力、身体、心气、压力五种资源；学习学识、手艺、表达、体谅、胆识五项技能；维护家人、师长、朋友、伴侣、晚辈、邻里六段关系；
- 每个行动在执行前显示代价、开放条件、预期变化和目标贡献；部分行动触发确定性检定，成功/失败都留下可读结果；
- 修理铺、河桥、学校、集市、镇志五项小镇基础跨世累积；一世结算从已解锁遗产中最多选择 3 件，下一世会把它们转成真实的初始资源、能力、关系或小镇入口；
- 16 项成就、10 条彩蛋、12 段人生片段和包含生活日志/现金流/工作履历的镇志档案提供长期收集、复盘和再开一局的理由；成就、彩蛋与片段都在游戏内显示结果，不依赖隐藏联网服务；
- 五张阶段场景图来自本地 PNG 资源；`audio.js` 使用离线 Web Audio 合成阶段配乐和行动音效，默认静音、主动开启，拒绝播放时文字层仍完整可用；
- localStorage v7 存档，旧版存档键保留但不自动迁移；支持导出 JSON、导入 JSON、清除当前世代和镇志回看；
- 全中文、本地单机、确定性 seed、响应式布局、键盘 1 / 2 / 3 选择、大字模式和基础 PWA 离线缓存。

## 设计边界

这是用于验证“目标明确、养成可规划、选择有代价、结算有成就、下一世有用途”的丰富版可玩切片，不是最终 GDD 锁定。内容采用固定 authored 数据；运行时不依赖联网、多人、内购或 AI。每世可以独立完成，同时通过小镇基础和最多三件遗产形成长期回声。

## 内容与代码

- `content.js`：静态起点、天赋、愿望、阶段、阶段图片元数据、23 个成长节点、生活行动、工作、物品、遗产、成就、彩蛋和人生片段；
- `audio.js`：本地阶段配乐与行动音效，完全离线且可选；
- `game.js`：存档、状态转移、生活经营、账单、条件与检定、片段收集、结算、成就解锁、遗产交接和渲染逻辑；
- `../content/content-manifest.json`：内容数量与 ID 契约；
- `../content/content-review.json`：A04 内容责任、A00 整合审阅和内容质量边界；
- `../tests/rich-loop-acceptance-20260829.md`：丰富版长流程、跨世、成就、彩蛋和移动端验收表。
- `../tests/life-sim-acceptance-20260829.md`：D4生活行动、工作、账单、物品、跨世和移动端验收表。
