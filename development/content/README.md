# 内容工程入口

当前内容是“D5生活经营与媒体反馈”切片：23 个固定成长节点、5 个阶段、5 张阶段场景图、69 个 authored 人生事件行动、7 个生活行动、6 个工作、6 件物品、5 个起点、8 个天赋、6 个愿望、16 件遗产、16 项成就、10 条彩蛋和 12 段人生片段。每世可以独立完成，跨世通过可解释的小镇基础、物品、遗产和镇志收集建立长期回声。

- `content-manifest.json`：节点、人生事件行动、生活行动、工作、物品、起点、天赋、愿望、遗产、成就、彩蛋、片段和阶段画面的数量与 ID 契约；
- `content-review.json`：A04 内容责任、A00 整合复核、媒体与片段触发、事实边界、语气敏感性和无运行时 AI 记录；
- `validate_content.py`：检查内容源、清单、审阅记录、数量、唯一 ID 和运行时边界。

每个人生事件行动、生活行动和工作必须明确写出描述、代价或条件、预期方向、效果和可见反馈；有检定的行动还必须说明技能、难度以及成功/失败反馈。每件物品必须说明价格、库存与场景加成；每件遗产必须说明下一世实际用途，并且用途必须和运行时效果一致。成就和彩蛋必须在结算、反馈或档案中有可见回报。

验证：

```powershell
python development/content/validate_content.py
python development/tests/validate_save_contract.py
```

本内容用于验证丰富性、可规划性和重玩基础，不等同于正式版最终内容锁定；扩写正式版前仍需按 G3/G4/G5/G6/G7/G8/G9/G10 门禁复审。
