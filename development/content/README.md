# 内容工程入口

当前内容是“丰富版每世人生循环”切片：23 个固定成长节点、5 个阶段、69 个互斥行动、5 个起点、8 个天赋、6 个愿望、16 件遗产、12 项成就和 8 条彩蛋。每世可以独立完成，跨世只通过可解释的小镇基础和遗产效果建立长期回声。

- `content-manifest.json`：节点、行动、起点、天赋、愿望、遗产、成就和彩蛋的数量与 ID 契约；
- `content-review.json`：A04 内容责任、A00 整合复核、事实边界、语气敏感性和无运行时 AI 记录；
- `validate_content.py`：检查内容源、清单、审阅记录、数量、唯一 ID 和运行时边界。

每个行动必须明确写出行动描述、代价或条件、预期方向、效果、愿望推进、即时结果和后续影响；有检定的行动还必须说明技能、难度以及成功/失败反馈。每件遗产必须说明下一世实际用途，并且用途必须和运行时效果一致。成就和彩蛋必须在结算、反馈或档案中有可见回报。

验证：

```powershell
python development/content/validate_content.py
python development/tests/validate_save_contract.py
```

本内容用于验证丰富性、可规划性和重玩基础，不等同于正式版最终内容锁定；扩写正式版前仍需按 G3/G4/G5/G6/G7/G8/G9/G10 门禁复审。
