# D3 核心循环垂直切片验收表

目标：验证玩家能在不读设计文档的情况下理解“这一世要做什么、现在能做什么、做完会影响什么、下一世拿什么继续”。

## 自动与静态验收

- [ ] `python planning/tools/validate_project.py` 通过；
- [ ] `python development/content/validate_content.py` 通过；
- [ ] `python development/tests/validate_save_contract.py` 通过；
- [ ] `node --check development/game/content.js` 通过；
- [ ] `node --check development/game/game.js` 通过；
- [ ] `node --check development/game/sw.js` 通过；
- [ ] 页面只加载本地资源，业务代码没有 `fetch`、`WebSocket`、`Math.random`；
- [ ] Service Worker 应用壳包含 `content.js`。

## 浏览器试玩验收

### 1. 开局是否能理解

- [ ] 首页明确显示“一世 8 回合”；
- [ ] 能看到 3 个起点和 3 个目标，选中后有明显状态；
- [ ] 开始前能看到“你是谁 + 你要完成什么”的摘要；
- [ ] 第一回合同时显示目标、当前资源和 3 个行动。

### 2. 选择是否可解释

- [ ] 每个行动卡都显示做什么、代价、预期结果；
- [ ] 条件不满足的行动会禁用，并显示缺少的具体条件；
- [ ] 选择后只能进入反馈，不能重复执行同一回合；
- [ ] 反馈同时显示数值变化和“它会怎样影响后面”；
- [ ] 反馈按钮能进入下一回合，进度从 1 / 8 走到 8 / 8。

### 3. 一世是否能完成

- [ ] 连续完成 8 个回合后进入结算，不会卡在最后一个行动；
- [ ] 结算显示目标完成度、这一世结果和小镇当前基础；
- [ ] 结算提供至少 1 件可选遗产，并说明下一世用途；
- [ ] 未选择遗产时确认按钮不可用；
- [ ] 选择 1—2 件后可以回到下一世开局。

### 4. 跨世是否真的发生

- [ ] 下一世开局显示上一世遗产，而不是只有一段叙事；
- [ ] 选择遗产后，下一世状态面板的资源 / 能力 / 关系或小镇基础确实变化；
- [ ] 完成第一世后刷新页面，仍能继续当前存档或从镇志查看记录；
- [ ] 镇志能显示世代、目标完成度、行动痕迹和交接遗产。

### 5. 存档边界

- [ ] 暂存回首页后可以继续当前人生；
- [ ] 导出后再导入，当前世代和小镇状态不丢失；
- [ ] 导入损坏 JSON 不覆盖现有存档；
- [ ] 清除当前世代后页面回到第一世，旧版键值不被主动删除；
- [ ] 移动端宽度下行动卡和结算卡不发生横向溢出。
