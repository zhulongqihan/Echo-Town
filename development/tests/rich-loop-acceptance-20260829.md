# 丰富版人生循环验收表

目标：玩家不读设计文档也能知道“我这一世想完成什么、现在能做什么、为什么要付出代价、这次选择会留下什么、下一世能拿什么继续”，并且愿意为了不同路线、成就和彩蛋再开一局。

- [x] `python development/tests/validate_save_contract.py` 通过；

## 浏览器长流程

### 1. 开局可规划

- [x] 首页清楚显示“一世 23 个成长节点”和五个成长阶段；
- [x] 能分别选择 5 个起点、8 个天赋和 6 个愿望，选中状态明显；
- [x] 开始前摘要同时说明起点、天赋、愿望、关键初始资源和上一世遗产；
- [x] 第一节点同时显示当前年龄、阶段、本世愿望、资源、技能、关系、小镇基础和 3 个行动；

### 2. 养成有反馈

- [x] 行动卡明确显示做什么、代价、开放条件、预期变化和愿望贡献；
- [x] 条件不满足时显示缺少的具体资源、技能、关系、小镇基础或彩蛋；
- [x] 选择后本回合锁定，反馈区显示资源/技能/关系/小镇/愿望的真实变化；
- [x] 反馈区显示“这会怎样影响后面”，并在有检定时显示确定性成功/失败结果；
- [x] 连续推进能看到阶段地图从童年走到后半生，进度从 1 / 23 走到 23 / 23；
- [x] 至少两条行动路线会在资源、技能、关系或可用条件上产生明显差异；

### 3. 一世有结算成就

- [x] 完成 23 个节点后进入结算，不会卡在最后一个行动；
- [x] 结算显示本世愿望完成度、最佳技能、关键关系、行动数量、小镇变化和人生结果；
- [x] 首次完成解锁“写下第一页”，结算页给出明确成就反馈；
- [x] 发现彩蛋后即时反馈，并能在档案页回看名称与线索；
- [x] 结算至少提供 3 件遗产候选，说明每件遗产的下一世实际用途；
- [x] 未选择遗产时确认按钮不可用；选择最多 3 件后进入下一世；

### 4. 跨世真的改变起点

- [x] 下一世开局显示上一世选中的遗产以及每件遗产的用途；
- [x] 开始下一世后，资源 / 技能 / 关系或小镇基础与无遗产起点存在可观察差异；
- [x] 选择不同起点、天赋或愿望能改变第一世的可用策略，而不是只换标题；
- [x] 完成一世后刷新页面，仍能继续当前人生或从镇志查看记录；
- [x] 镇志能显示世代、起点、天赋、愿望、目标完成度、行动痕迹、成就、彩蛋和交接遗产；

### 5. 存档、离线和移动端

- [x] 暂存回首页后可以继续当前人生，当前节点与反馈不丢失；
- [x] 导出后清空并导入，世代、当前节点、小镇、遗产、成就和彩蛋不丢失；
- [x] 导入损坏 JSON、旧版本 JSON 或超限文件均拒绝，且不覆盖现有存档；
- [x] 清除当前世代后页面回到第一世，旧版键值不被主动删除；
- [x] 390×844 宽度下行动卡、结算卡、档案页无横向溢出；
- [x] 键盘 1 / 2 / 3、大字模式和无音频情况下，关键规则与反馈仍完整可用；
